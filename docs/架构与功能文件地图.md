## 一、技术栈与分层

| 层 | 技术 | 根目录 |
|----|------|--------|
| 前端 | Vue 3 + Vite 6 + Pinia + Vue Router + Element Plus（按需） | `frontend/` |
| 后端 | Java 17 + Spring Boot 3.2.7 | `src/main/java/com/secondhand/mall/` |

```
浏览器 Vue3 SPA
  → fetch /api/**
  → Controller（手写登录/管理员校验）
  → Service（@Transactional + 行锁 + @Audited）
  → Repository (JPA) → MySQL
```

## 五、资金与并发约定（改代码必读）

1. **订单行锁**：状态变更、支付、取消、退款一律 `orderRepository.findByIdForUpdate`，锁内复核 status。
2. **用户余额**：`userRepository.findByUsernameForUpdate` 后再加减余额；流水与余额同事务。
3. **商品库存**：下单/取消/关单回补必须 `productRepository.findByIdForUpdate`（B-05 例外待修）。
4. **建议锁序**：`order → product → buyer → seller`（当前 `cancelOrder` 与 `settleRefund` 不一致，见 B-06）。
5. **扣款只在 `payOrder`**；`pending_payment` 未扣款，取消/关单只回补库存不退款。
6. **托管打款**：`sellerPaid` 默认 false；完成/评价后 `releaseToSeller`（B-08 有洞）。
7. **优惠券**：支付时 `consume`，取消/全额退款 `releaseByOrder`。
8. **金额**：全链路 `BigDecimal`；`paidTotal = 单价×数量 - discountAmount`。

## 六、状态机速查

**订单**（`constant/OrderStatus.java` + `OrderService.VALID_TRANSITIONS`）：

```
pending_payment → unshipped | cancelled
unshipped → shipped | cancelled
shipped → received
received → completed
after_sale → return_shipping → return_sent → refunded
（售后专用接口驱动；禁止 after_sale 直接 cancelled）
```

定时任务：`OrderPaymentTimeoutService`（30 分钟关待付）、`OrderAutoCompleteService`（7 天自动完成）、`OrderAfterSaleTimeoutService`（72h 自动同意 / 7 天未寄回关售后 / 7 天未确认自动退款）。

**商品**（`constant/ProductStatus.java`）：`pending → active | rejected`；`active ⇄ inactive`；`sold`；`deleted`（回收站）。
